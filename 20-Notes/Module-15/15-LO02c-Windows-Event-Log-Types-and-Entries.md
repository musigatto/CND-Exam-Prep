# Windows Event Log Types and Entries (§15.LO#02c)

> **LO#02: Discuss log monitoring and analysis on Windows systems** _(Mod 15 p14)_
> Covers pp23–26.

## Event Viewer _(Mod 15 p23)_

- A tool that provides a **quick overview of when, where, and how an event occurred**
- Provides **detailed information about events, errors, warnings, and information messages** generated by the OS
- **Especially useful for troubleshooting issues**
- Events are stored in Windows logs files under categories: **application, security, system, setup, and forwarded**

## Event log types and what each records

| Type | Definition as printed | Source |
|---|---|---|
| **Application event log** | Events related to the **applications installed on the system**; specifically **informational events, warnings from the applications, and errors raised in an application**. e.g. Microsoft Excel breaks down → logged with the name of the application and why it crashed | _(Mod 15 p23)_ |
| **Security event log** | Events related to **Windows security**; specifically **log-on/log-off activities, resource access**, and information based on **Windows system's audit policies**. **Analyzed by network defender to identify attempted and/or successful unauthorized activities.** e.g. the system attempts to verify account credentials when an end-user tries to log-on | _(Mod 15 p23)_ |
| **Setup event log** | **Enterprise-focused events that cover all actions that occurred during installation**; e.g. the location of **memory dump from bug checks** | _(Mod 15 p23)_ |
| **System event log** | Events logged by the **OS segments**; specifically **hardware changes, system changes, device drivers**, and all **machine-related activities** (e.g. failure of the device driver) | _(Mod 15 p23)_ |
| **Forwarded event log** | Events **received from other systems present on the same network** | _(Mod 15 p24)_ |
| **Custom log** | "Facilitates an application to **change the size of the log or add access control lists (ACLs) without influencing other applications**" | _(Mod 15 p24)_ |

## What a log entry contains _(Mod 15 pp24–25)_

| Field | Definition as printed |
|---|---|
| **Level** | Defines the **severity** of the event. Values: **Error, Warning, Information, Success Audit, Failure Audit** |
| **Keywords** | A **set of categories or tags** that defines a type of event. Values: **AuditFailure, AuditSuccess, Classic, Correlation Hint, Response Time, SQM, WDI Context, WDI Diag** |
| **Date and time** | The date on which an event occurred |
| **Source** | The source of the event |
| **Event ID** | **A unique event ID is assigned for each type of event** |
| **Task category** | Defines the **category of ask** _(printed typo)_ |
| **User** | The **username** on whose behalf a particular event was generated |
| **Operational code** | The **activity that an event was performing** when an event was raised |
| **Log** | The **name of the log** on which the event was recorded |
| **Computer** | The **computer name** on which the event was raised |

The p23 callout prints an abridged version of the same list — **Level, Keywords, Date and Time, Source, Event ID, Task Category** _(Mod 15 p23)_.

### Additional event properties _(Mod 15 p25)_

- Added or removed by clicking **View** (menu bar) and then **Add/Remove Columns**
- **XML representation of an event** → click the **Details tab** in an event's properties

| Property | Definition as printed |
|---|---|
| **Process ID** | The **process identification number** for the generated event |
| **Thread ID** | The **thread identification number** for the generated event |
| **Processor ID** | The **processor identification number** that processed the event |
| **Session ID** | The **terminal server session identification number** in which the event was raised |
| **Kernel time** | Time taken in executing **kernel-mode instructions** in **CPU time units** |
| **User time** | Time taken in executing **user-mode instructions** in **CPU time units** |
| **Processor time** | Time taken in executing kernel-mode instructions in **CPU ticks** |
| **Correlation ID** | The **activity in the process for which the event was involved** |
| **Relative correlation ID** | The **related activity in a process for which the event was involved** |

## Event Types _(Mod 15 p26)_

> "Events are categorized into **five types**, based on their **severity levels**."

| Event Type | Description as printed | Example as printed |
|---|---|---|
| **Error** | A **significant problem such as loss of data or loss of functionality** | A **service fails to load during startup** → an Error event is logged |
| **Warning** | **Not necessarily significant but may indicate a possible future problem**. Also: an application that **can recover without loss of functionality or data** can classify the event as a Warning | **Disk space is low** → a Warning event is logged |
| **Information** | Describes **successful operation of an application, driver, or service**. "It is **generally inappropriate for a desktop application to log an event each time it starts**" | A **network driver loads successfully** |
| **Audit Failure** _(prose: Failure Audit)_ | Records an **audited security access attempt that fails** | A user tries to access a **network drive and fails** |
| **Audit Success** _(prose: Success audit)_ | Records an **audited security access attempt that is successful** | A user's **successful attempt to log on** to the system |
