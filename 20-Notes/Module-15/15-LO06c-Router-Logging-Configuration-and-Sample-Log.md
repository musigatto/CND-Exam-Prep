## `include` with a regular expression _(Mod 15 pp96–97)_

> "The `include` command can also used with **regular expressions for identifying intrusions**. See
> below for an example:"

```text
Router#show logging I include 172.16.1.92 . * \ (137\)
002064: Mar 30 2018 11:41:20. 659 EDT: denied tcp 172.16.1.92 (17587) ->
192.168.
002065: Mar 30 2018 EDT: denied tcp 172.16.1.92 (58564) -> 192.168.
002067: Mar 30 2018 11:41:23. 663 EDT: denied tcp 172.16.1.92 (17755) ->
192.168.
Router#
```

> "In the above example, **`show logging | include 172.16.1.92 . * \ (137\)` will display all the log
> entries with source IP address `172.16.1.92` and destination port `137`**." _(Mod 15 p97)_

### Anatomy of a denied-connection router log line _(Mod 15 p96–97)_

Read against the printed line `002064: Mar 30 2018 11:41:20. 659 EDT: denied tcp 172.16.1.92 (17587) -> 192.168.`:

| Part | Value in this line |
|---|---|
| sequence number | `002064` |
| timestamp | `Mar 30 2018 11:41:20. 659 EDT` |
| action | `denied` |
| protocol | `tcp` |
| source address | `172.16.1.92` |
| source port | `17587` |
| destination | `192.168.` — **truncated on the page** |

Other values printed across the three lines: source ports `17587`, `58564`, `17755`; sequence numbers
`002064`, `002065`, `002067`; timestamps `Mar 30 2018 11:41:20. 659 EDT`, `Mar 30 2018 EDT` (no time
on that line), `Mar 30 2018 11:41:23. 663 EDT`.
