# Mobile Application, Data, and Network Security (§7.4)

Enterprise-level mobile security management solutions only deliver their benefits when backed by **strong mobile device security practices**.

## Mobile Application Security Best Practices
- Ensure apps **do not save passwords**
- Avoid using **query string** while handling sensitive data
- **Code obfuscation + encryption** to secure application source code
- Implement **two-factor authentication**
- Use **SSL/TLS** to send data over secure channels
- Avoid **caching app data**
- Perform **validation checks on input** data
- Implement **secure session management**
- Protect application settings
- Use **server-side authentication**
- Use cryptographic algorithms + key management
- Build **threat models** to defend data
- Employees download **trusted apps from enterprise app stores**
- Use **containerization** for critical corporate data
- Perform **regular mobile security audits**
- **Regular software updates**
- Implement **jailbreak protection**

## Mobile Data Security Best Practices
- Secure mobile infrastructure + strengthen endpoints
- **Encrypt the data stored on the device**
- Enable **over-the-air encryption** (SSL, TLS, VPN, WPA2)
- **Backup mobile data periodically**
- Do **not store extremely sensitive information** on mobile devices
- Do not store passwords or PINs **as contacts** on the phone
- Store data in **private data centers** + implement device authentication
- Maintain access control for devices + data
- **Avoid public Wi-Fi networks**
- Set **automatic device locks** when not in use
- Users access corporate data from a **secure central location**
- Complete software updates/patches **in a timely manner**
- Educate employees to recognize **suspicious emails**
- Keep **antivirus/anti-malware updated**
- Train employees to **encrypt hard drives + USBs** before storing work-related data

## Mobile Network Security Guidelines
- **Disable interfaces** (Bluetooth, infrared, Wi-Fi) when not in use
- Set Bluetooth devices to **non-discoverable mode**
- Avoid unknown Wi-Fi networks + public Wi-Fi hotspots
- Connect to **encrypted Wi-Fi networks only**
- Configure web accounts to use **secure connections**
- **Isolate user groups with different SSIDs**; segment traffic for groups to different **VLANs**
- Apply different **firewall rules/filters** to different user-group/device combinations
