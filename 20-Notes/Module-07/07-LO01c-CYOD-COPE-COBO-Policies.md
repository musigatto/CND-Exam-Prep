# CYOD, COPE, and COBO Policies (§7.1)

## Choose Your Own Device (CYOD)
- Employees select devices (laptops, smartphones, tablets) from a **company-approved list**; company buys it; employee uses it per access privileges
- Gaining more attention than BYOD (securing BYOD is hard across many devices; employees store personal + professional data regardless of ownership)

### CYOD advantages
- One smartphone + one tablet per user · lower hardware costs vs COPE · users keep control of their technology · stricter procurement standards than BYOD · streamlined support · preinstalled security solution + predefined firewall/network settings · easy record-keeping (small device catalog) · employees comply with data/information-management requirements

### CYOD disadvantages
- IT staff may dislike the choices · complex procurement vs BYOD/COPE · replacement/repair problems · must keep pace with mobile tech/apps · slower deployment timeframe

### CYOD implementation (5 steps)
1. Define approved set of devices (corporate-sanctioned list + plans)
2. Allow employees to select from approved set + build technology portfolio (role-based catalogs; pre-provision apps/settings, e.g., Outlook with employee credentials)
3. Develop policies (device types, OS versions, model numbers → resource-heavy; e.g., only a specific Android model/OS version)
4. Security: virus protection · encryption · network access controls + authentication · data wipes + remote locks (lost/stolen)
5. Support: dedicated helpdesk — device troubleshooting · service troubleshooting · activating devices · deactivating devices · managing service requests

## Corporate Owned, Personally Enabled (COPE)
- Employees use + manage devices **purchased by the organization**; larger enterprises favor COPE
- **Cheaper than BYOD** (bulk purchase below retail); reduces BYOD risks via stringent policies + protections

### COPE advantages
- Work/life balance on one device · fewer security concerns than BYOD/CYOD · personal apps · enhanced control/authority over devices · prevents carrying two phones · org retains device ownership · free installation of management software + MDM integration · solves regulatory/legal issues of deleting data on lost/stolen devices · economizes IT resources

### COPE disadvantages
- Must purchase devices · monitoring policies must be established · org fully responsible for keeping up with latest tech · potential productivity issues (less user freedom) · **slowest deployment timeframe**

### COPE implementation (5 steps)
1. Purchase computing resources/devices (preapproved from vendors, centrally designed plan)
2. Employees work with company-owned device + build portfolio: containerization/virtualization to separate professional vs personal use · manage/prohibit data sharing between containers · secure PII with org data (device network access control) · secured apps from trusted sources
3. Develop policies: employees understand + sign-off on leaving-company terms · decide device procurement/retention after leaving · procedure to remove all corporate data/assets
4. Security: apply security controls, restrict features against malware/data leaks, monitor for data breaches or jailbreaking
5. Support: dedicated helpdesk (troubleshooting, activation/deactivation, service management)

## Company Owned, Business Only (COBO)
- Org-purchased devices restricted to **business use only**; often single-application devices
- Examples: inventory system with embedded barcode scanner · **Blackberry** = classic COBO environment

### COBO advantages
- Company retains full control over all apps + data · uniform system landscape (org purchases device)

### COBO disadvantages
- High purchase cost · employees must carry ≥ 2 devices

### COBO implementation (5 steps)
1. Prohibit personal use of devices
2. Single-application devices, or smartphones with prohibited personal use + highly granular device/app/data management
3. Develop policies: MDM + MAM solutions must meet company requirements
4. Security: fully locked-down devices, granular policy control, prevent app downloads
5. Support: dedicated helpdesk (troubleshooting, activation/deactivation, service management)
