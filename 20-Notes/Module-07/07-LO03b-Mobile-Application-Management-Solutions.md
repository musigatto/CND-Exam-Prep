# Mobile Application Management (MAM) Solutions (§7.3)

- **MAM** = software/service to **secure, manage, and distribute enterprise applications** on employee mobile devices, without interfering with device ownership (BYOD)
- Enables **separation of enterprise apps + data from personal content** on the same device

## Common MAM Features
- Device activation · enrollment + provisioning capabilities · remote wipe + other device-level functionalities · remote management **without possessing the device** · minimal admin intervention + zero user action

## Services Provided by Enterprise Application Management (MAM)
- Application delivery (enterprise app store) · software licensing · application configuration · application authorization · application usage tracking · application lifecycle management · application updating · application performance monitoring · user authentication · crash log reporting · user/group access control
- **App version management · push services · reporting + tracking · usage analytics · event management · app wrapping**

## MAM Examples
- **Microsoft Intune (Intune MAM):** publish, push, configure, secure, monitor, update mobile apps
  - Two configurations:
    - **Intune MDM + MAM** — MAM + app protection policies on devices **enrolled in Intune MDM**
    - **MAM without device enrollment (MAM-WE)** — MAM + app protection policies on devices **not enrolled** in Intune MDM
- **MobileIron MAM:** mobile application security framework; distribution, protection, management of apps
- **App47 MAM:** securely delivers mobile apps to diverse employee/customer audiences
- **Scalefusion MAM:** distributes in-house + public apps via Scalefusion Enterprise Store or Google Play
