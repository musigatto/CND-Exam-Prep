# IoT Devices — Basics, Need, and Application Areas (§8.1)

## What is IoT?
- **IoT** = Internet of Things, aka **Internet of Everything (IoE)** — web-enabled computing devices that sense, collect, and send data using embedded **sensors**, **communication hardware**, and **processors**
- A **"thing"** = device implanted on natural, man-made, or machine-made objects, with network communication functionality
- Work on a **three-dimensional plane**: "anyone, any time, anything, any place"
  - Outdoors/indoors · daytime/night · on the move · indoor (away from PC) · at the PC
- Interaction types: **H2H** (human-to-human, no PC) · **H2T** (human-to-things, generic equipment) · **T2T** (things-to-things, between PCs)
- Key IoT features: connectivity, sensors, AI, small devices, active engagement

## IoT Technology Components (4 primary systems)
| Component | Role |
|---|---|
| **Sensing technology** | sensors acquire info (temperature, gases, location, industrial machines, patient health) |
| **IoT gateways** | bridge internal (device) ↔ external (end user) networks; push data to user/cloud |
| **Cloud server / data storage** | store + analyze data; transmit processed output to user |
| **Remote control (mobile apps)** | phones/tablets/laptops monitor, control, retrieve, act on IoT devices |

## Working Example (smart security system)
1. Security system → gateway → Internet + cloud
2. Cloud stores device IDs, status, access history
3. Cloud connection via **web services**
4. User app → authenticate (matching cloud credentials) → cloud identifies device ID → command via gateways
5. Unusual activity → alert to cloud → matched to user → alert to end user

## Application Areas (Table 8.1)
| Sector | Application groups | Example devices |
|---|---|---|
| Commercial/Institutional Buildings | HVAC, transport, fire & safety, lighting, security | access control |
| Industrial | process, energy supply/demand, oil/gas, infrastructure | turbines, windmills, UPS, batteries, rigs, pipelines |
| Consumer & Home | awareness & safety, convenience & entertainment | digital cameras, dishwashers, washers/dryers, lights, MP3 players, game consoles, alarms |
| Healthcare & Life Science | care, in-vivo/home, research | MRI, PDAs, implants, surgical equipment, telemedicine |
| Transportation | non-vehicular, vehicles, transportation systems | vehicles, ships, planes, tolls, navigation |
| Retail | retail/hospitality/stores | POS terminals, vending machines, tags, cash registers |
| Security/Public | surveillance, tracking, public safety, emergency service | radars, weapons, ambulances, police/fire |
| IT & Networks | enterprise IT/data center | servers, storage, PCs, routers, switches, PBXs |

## Sector usage (notable)
- **Smart buildings/devices:** thermostats, lighting, security systems connected to Internet
- **Healthcare:** wearables, health monitors, implanted pacemakers, ECG/EKG, surgical equipment, telemedicine
- **IIoT** (Industrial IoT): 3 growth approaches — (1) increased production/revenue, (2) intelligent tech changing manufacturing, (3) new hybrid business models
- **Transportation:** vehicle-to-vehicle, vehicle-to-roadside, vehicle-to-pedestrian; traffic, navigation, parking
- **Retail:** payments, advertisements, product tracking (anti-theft, revenue)
- **IT/networks:** printers, faxes, copiers, PBX monitors
